# SKILLS-HOWTO

Quick-reference guides for AI coding agent skill systems — what each one does,
how to install it, and how to use it day to day.

## Guides

| Guide | Covers |
|---|---|
| [SUPERPOWERS-HOWTO.md](SUPERPOWERS-HOWTO.md) | [obra/superpowers](https://github.com/obra/superpowers) — a composable-skill methodology (clarify → design → plan → TDD → review → merge) that auto-triggers via a bootstrap skill. |
| [GSD-CORE-HOWTO.md](GSD-CORE-HOWTO.md) | [open-gsd/gsd-core](https://github.com/open-gsd/gsd-core) — "Git. Ship. Done." Spec-driven development that offloads research/planning/execution to fresh-context subagents to fight context rot. |
| [GSTACK-HOWTO.md](GSTACK-HOWTO.md) | [garrytan/gstack](https://github.com/garrytan/gstack) — a virtual engineering team (CEO, eng manager, designer, reviewer, QA, security, release) as slash commands: Think → Plan → Build → Review → Test → Ship → Reflect. |
| [HARNESS-SKILLS-HOWTO.md](HARNESS-SKILLS-HOWTO.md) | [harness/harness-skills](https://github.com/harness/harness-skills) — skills for the Harness.io CI/CD platform: generate pipeline YAML, manage resources, debug failures, analyze cost. |
| [ANDREJ-KARPATHY-SKILLS-HOWTO.md](ANDREJ-KARPATHY-SKILLS-HOWTO.md) | [multica-ai/andrej-karpathy-skills](https://github.com/multica-ai/andrej-karpathy-skills) — a single CLAUDE.md/skill encoding four behavioral principles (think before coding, simplicity first, surgical changes, goal-driven execution) to curb common LLM coding mistakes. |

Each guide is self-contained: source repo, install steps per harness, and the
commands/workflow you'll actually use.
